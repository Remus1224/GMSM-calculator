# 2026/10/06 變更紀錄

本文件記錄功能分支的變更；正式網站須在合併與部署後才會更新。

## 資訊與計算工具

- 新增「也許有用的資訊」入口與九項資訊：創世解放、海洛斯的封印、星座核心、光之聖所 祈禱、六轉核心、寵物食品、輔助武器鍊成、神秘/真實符文、星力強化。
- 新增寵物食品計算機，支援三隻寵物的等級需求、已持有食品扣除、20/30 個組合包需求與購買價格參考，並提供主選單入口。
- 星力強化資料依一般裝備與露塔必思裝備分頁，排除超出裝備上限的星數，零機率顯示「-」，並註明未套用加成、保護與費用折扣。
- 資訊頁提供遊戲版本、素材圖示、合計與圖片儲存；個別資料版本與來源以頁面及資料檔為準。

## 介面與維護

- 調整主選單分類、排序與入口寬度；資訊入口使用共通卡片樣式。
- 整理共通下拉選單、勾選、呼吸提醒、圖片匯出及手機表格分頁樣式；六轉表格保留等級欄並以兩個核心為一組滑動。
- 移除重複的 Beta 目錄，改用 Git 分支測試，更新正式入口與 CI 檔案檢查。
- 修正清理舊程式時造成的 JavaScript 語法錯誤。
- 介面修改前後對照完成檢視後只保留本機，不納入公開分支最新內容。

## 使用統計

- 四個網站入口統一載入 GA4，記錄工具/資訊開啟、每次進入的首次操作與成功圖片匯出。
- 事件帶入中文工具名稱；不傳送等級、價格或其他使用者輸入值。本機與私有 LAN 預覽不送出新事件。
- 事件定義與後台設定方式：[GA4 工具追蹤](../analytics/GA4-TOOL-TRACKING.md)。
- GA4 帳戶截圖與個人後台設定紀錄僅保留本機，不納入公開儲存庫。

## 檢查與發布

本機交接與調查歷史集中至 `.local-docs/` 並排除上傳；公開說明整併為[資料規則](../DATA-NOTES.md)、[共通樣式維護](../MAINTENANCE.md)及[上傳內容分類](../REPOSITORY-CONTENTS.md)。

GitHub Actions 的 `Validate project` 會檢查 JavaScript 語法、必要檔案、正式入口及共通模組路徑。這些靜態檢查不取代遊戲數值與桌面/手機實際操作確認。

合併前請由維護者檢視 Pull Request 與實際畫面；本分支上傳本身不會更新正式網站。
