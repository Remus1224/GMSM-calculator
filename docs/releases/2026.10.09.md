# 2026.10.09 — Game Info & GA4 Milestone

本次更新以「也許有用的資訊」正式擴充、寵物食品計算機、全站使用統計及網站架構整理為核心。

延續 `2026.10 Unified Glass UI Baseline`，進一步完善玩家查詢遊戲資料與使用工具的體驗。

## 新增「也許有用的資訊」

正式整合 **11 項遊戲資訊**，並依用途分類：

**成長與強化**
- 創世解放
- 海洛斯的封印
- 六轉核心
- 星座核心
- 光之聖所祈禱
- 極限屬性
- 神秘／真實符文
- 寵物食品
- 星力強化
- 輔助武器鍊成

**機率與期望值**
- 輪迴星火

資訊頁依項目提供對應數據、材料需求、機率或費用資訊，部分頁面支援互動選擇、合計與圖片儲存。

資料依各頁標示的遊戲版本與來源為準，部分數值與實際結果可能隨遊戲更新而改變。

## 新增寵物食品計算機

提供寵物升級食品需求估算，包含：

- 最多三隻寵物的需求
- 已持有食品數量扣除
- 20／30 個組合包需求
- 購買價格參考

方便玩家估算寵物培養所需的食品及購買數量。

## GA4 使用統計整合

全站導入共通工具事件，支援：

- `tool_view`：工具與資訊頁開啟
- `tool_use`：每次進入後的首次有效操作
- `tool_export`：成功產生並儲存圖片

事件可依中文工具名稱、分類及入口區分，協助了解哪些工具與資料較常被使用。

資訊首頁也有獨立的開啟紀錄。

追蹤事件不傳送玩家輸入的等級、價格、文字內容或計算數值。本機與私有網路預覽不送出新追蹤事件。
