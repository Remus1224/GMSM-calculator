# 資訊資料與計算規則

網站讀取 `game-info/data/catalog.json` 與各項 JSON；本說明供維護者理解資料定義，頁面不讀取此文件。遊戲版本與来源欄位以各 JSON 為準，不以文件修改日期代替遊戲版本。

## 寵物食品

- 資料：`game-info/data/pet-food.json`。來源為《PetLevel_AllRoutes_中文整理版.xlsx》的 `LunaPetit 1-50` 工作表 `A1:F50`；僅採用 Lv.1 至 Lv.50 路線，遊戲版本 2026/09。
- 每個食品提供 300 經驗；完整路線為 520,500 經驗、1,735 個食品。表格第二段的累積值仍從 Lv.1 起算。
- 計算機以起始等級 0 經驗計算。每隻勾選的寵物先加總升等區間的經驗，再除以 300 向上取整，最後加總各寵物食品需求；不將寵物間剩餘經驗互相抵用。
- 待購數量為 `max(0, 食品總需求 - 已持有食品)`。20/30 個組合包的單買包數各自向上取整。
- 輸入價格作為市場參考：比較每個食品成本，以較低成本換算兩種包裝的購買價格上限，並向下取到小數點後兩位。使用整數分幣與交叉相乘比較，不假設市場有足夠庫存。單買總價僅作參考。

## 神秘/真實符文

- 資料：`game-info/data/rune-requirements.json`；來源為主站 `script.js` 的符文計算機需求及費用常數，遊戲版本 2026/07。
- 顯示已提供升級需求的六種祕法符文與兩種真實符文。同一種類各地區的材料及費用相同；地區圖示不代表合計要乘六或乘二。
- 合計為單顆符文從 Lv.1 升至最高等級的材料與楓幣。

## 輔助武器鍊成

- 資料：`game-info/data/secondary-weapon.json`；來源為《副武器鍊成_玩家版完整表.xlsx》與 `EvidenceLedger.csv`。資料保留來源檔案 SHA-256 與來源列索引，未提供遊戲版本。
- 能力數值為鍊成額外能力的累積值，不含武器基礎能力；括號表示本級增加值。Lv.1 為首次轉換，Lv.2–10 為逐級鍊成。
- 材料及楓幣為單次基礎消耗；合計為每級一次成功的理論最低成本，不是期望花費。罕見、傳說、神話的魯碧安/楓幣合計依次為 650/70,000,000、1,380/147,000,000、2,950/240,000,000。
- 罕見 Lv.8 最終傷害採來源修正後的 1%。已轉換同目標物品的特殊零消耗分支，不取代一般 Lv.1 成本。

## 星力強化

- 資料：`game-info/data/starforce-requirements.json`；來源為《楓之谷M_星力強化_玩家版完整表.xlsx》的 `1-36星機率!A6:G41` 與 `常見費用比較!A6:D41`，遊戲版本 2026/10。
- 一般裝備顯示目標 1–36 星；露塔必思帽子/武器顯示 1–30 星，上衣/褲子顯示 1–21 星。原始資料的額外費用列保留於 JSON，顯示範圍由頁面限制。
- 機率為基礎機率，0% 顯示 `-`；楓幣為單次費用，不是達標總成本或期望值。
- 不套用星星捕捉、幸運日、安全盾牌、裝備保護卷軸及費用折扣；不包含飾品、輔助武器與其他活動裝備。裝備是否可升至特定星數仍受實際上限與擴充條件限制。

## 極限屬性

- 資料：`game-info/data/hyper-stat-requirements.json`；來源為 `HyperStatPlayerTable.csv`，共 15 項能力、385 列，遊戲版本由維護者確認為 2026/10。JSON 保留來源檔名、SHA-256、原始能力名稱與效果字串。
- 下拉選單選擇能力，同一表格列出目前等級、目前效果、升下一級費用與累積楓幣。Lv.0 累積為 0；最高等級沒有下一級，該欄顯示「—」。累積楓幣計到目前等級，不含下一級費用。
- 追加技能的次數與倍率在電腦並排、手機分兩行；Lv.1～25 固定的 1.5 秒移到表格卡片說明，並保留 Lv.0 為 0 秒的註記。若未來資料秒數不再固定，會恢復每列顯示秒數。
- 星力最高 Lv.20，其餘能力最高 Lv.25；滿級累積費用分別為 799,000,000 與 1,449,000,000 楓幣。依來源保留上限，不從其他能力補出星力 Lv.21–25。
- 追加技能效果的 hits/sec 只翻譯為次/秒，不推定時間意義。Buff 道具及 Fever Buff 時間在 CSV 未明示單位，顯示原始數值，不自行補上單位。
- 第一版新增資訊頁，不更動既有極限屬性計算機的等級與計算邏輯。

- 沿用共通下拉選單與固定數字槽位，不再保留矩陣、費用分頁或滿級摘要卡。最大傷害以「萬」顯示，原始 JSON 數值保留，完整值提供滑鼠提示與輔助閱讀。桌面與手機皆顯示四欄；圖片匯出跟隨目前能力並包含效果與費用。

## 輪迴星火

- 資料：`game-info/data/flame-expectations.json`；來源為《Reincarnation_Flame_Analysis.xlsx》的 `三能力整合版!A14:N19`，遊戲版本 2026/09。JSON 保留來源檔名、工作表、SHA-256 與列索引，共三項能力、六組部位。
- 以已有兩排的裝備重洗為基準；整理模型假設候選結果等權、兩排獨立且同能力可重複，不另計第二排出現率。單排機率以單一詞條計算，雙排要求兩個詞條同能力，兩者不限制數值；雙排頂要求兩排皆為指定能力的最高值。
- 候選數為 N、指定能力有四階數值時，單排機率為 `4/N`、雙排為 `(4/N)^2`、雙排頂為 `(1/N)^2`，平均需求為 `1/p`。期望值不是保底；資料與期望值保留完整精度，單排/雙排機率顯示兩位小數、雙排頂顯示三位，不以畫面顯示值重新計算。
- 最終傷害、無視防禦與道具掉落率各用一張四欄表，能力名稱與部位併入同列表頭。期望值附「顆」、機率附百分號，寬欄左右排列、窄欄上下置中；素質列並排顯示傳說與神話，整數不補 .0。說明與遊戲版本直接顯示，圖片匯出包含圖示對照、三張表及完整說明。
- 資訊首頁由 catalog 分為「成長與強化」及「機率與期望值」，輪迴星火屬後者。入口使用提供的 `assets/menu/icon_輪迴星火.png`；星火與裝備素材分別存於 `assets/flame/`、`assets/equipment/`，保留原始 PNG。
- 分類圖示自光之聖所的 `CommonSimpleAtlas__8873075961046716041.png` 精準裁切為獨立 PNG；座標由 `light-sanctum-pray/runtime/ui-static-scene-data.js` 的 atlas/sprite 資料取得，`assets/equipment/category-icons-source.json` 保留來源雜湊、座標與輸出雜湊。網站只讀取獨立 PNG，不依賴原圖集載入；`icon_emblem` 經維護者確認用於「徽章」，機器人另使用提供的獨立素材。
- 分類圖示沿用共通容器，日間深色、夜間白色。圖示中文對照卡收錄十二個分類部位，省略道具掉落使用的八個實物圖示；最終傷害在機器人後換行，無視防禦在護肩後換行。掉落圖示依序為臉飾、眼飾、戒指、項鍊、紅/藍口袋、耳環、胸章。
