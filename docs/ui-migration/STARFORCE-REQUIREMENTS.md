# 星力強化資料表

來源為使用者提供的《楓之谷M_星力強化_玩家版完整表.xlsx》：`1-36星機率` 工作表 `A6:G41`，費用參考 `常見費用比較` 工作表 `A6:D41`。資訊頁使用既有 `starforce-requirements.json`，不更動來源活頁簿或原始資料值。

頁面提供一般主武／防具、露塔必思帽子／武器、露塔必思上衣／褲子三種每次費用選項。共用36列機率資料；一般裝備顯示目標1–36星，露塔必思帽子／武器顯示目標1–30星，露塔必思上衣／褲子顯示目標1–21星。來源資料中帽子／武器仍保留31星費用與 `lastTarget: 31` 記錄；依使用者指定，資訊頁不顯示目標31–36星。Excel原始資料完整保留。

費用缺值顯示「—」。費用列不是達標總成本，不加入期望值或合計。資料列保留於 DOM，依目前費用類型切換顯示範圍，不重建表格。

資料表到36星不代表每件裝備都能升至36星，實際上限取決於裝備上限與擴充條件。提醒說明本表不套用星星捕捉、幸運日、安全盾牌、裝備保護卷軸及費用折扣；每次強化費用依裝備類型而異，本表不包含飾品、輔助武器與其他活動裝備。依使用者指定，移除露塔必思顯示星數提醒與末尾重複的星星捕捉提醒，保留裝備上限提醒。

頁面使用版本註記與表格匯出。未執行瀏覽器或功能測試。

手機上露塔必思費用選項以「露塔必思」及裝備部位作固定詞組換行，避免詞組中間斷字。0%機率顯示為「-」，非零機率維持百分比格式。
