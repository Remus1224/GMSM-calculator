更新日期：2026-10-06。接續現有工作目錄的 Game Info 共通樣式版本；沒有提交、推送或改動其他需求表資料。

## 入口與資料

- 入口：也許有用的資訊 → 輔助武器鍊成需求表。
- 路徑：`game-info/?page=secondary-weapon`。
- 品級連結：`&grade=rare`、`&grade=legendary`、`&grade=mythic`。
- 資料：`game-info/data/secondary-weapon.json`。
- 使用者來源：`EvidenceLedger.csv`、`副武器鍊成_玩家版完整表.xlsx`。兩個檔案的 SHA-256 存在資料 JSON 的 `source.files`，來源列索引存在各級 `sourceIndex`。
- 已比對三品級共 30 級、210 個靜態數值、120 個本級能力增加值，以及整理表的三品級合計。

## 數據定義

表內物理攻擊、魔法攻擊、BOSS 攻擊、最終傷害都是鍊成額外能力的累積值，不含武器基礎能力。括號為本級相較上一級的增加值；首次轉換以前級附加值 0 計算。

Lv.1 是首次轉換；Lv.2～10 是逐級鍊成。魯碧安（Item ID 51076）和楓幣均為單次基礎消耗，不是平均成本。合計只表示各級全部一次成功的理論最低成本：

| 品級 | 魯碧安 | 楓幣 |
| --- | ---: | ---: |
| 罕見 | 650 | 70,000,000 |
| 傳說 | 1,380 | 147,000,000 |
| 神話 | 2,950 | 240,000,000 |

罕見 Lv.8 的最終傷害採來源修正後的 **1%**。不推算伺服器隨機機制、失敗懲罰或平均次數。EvidenceLedger 所述已轉換同目標物品的零消耗特殊分支，不取代一般首次轉換的 Lv.1 成本。來源沒有提供遊戲版本，因此不以製作日期冒充遊戲版本。

不使用朗基努斯武器素材，已移除三品級的 `weaponIcon` 預留欄位、圖片容器、渲染及尺寸樣式。目錄入口仍暫用現有製作圖示，可由使用者另行指定入口素材。

## 手機第三輪：連續欄位（2026-10-06）

本節取代第二輪的三張子表分頁排版。固定鍊成區間縮至 76px（360px 以下 72px），固定欄與資料的間距使用共通欄位間距的一半。首次轉換顯示「首次 → Lv.1」，完整語意保留在說明和無障礙標籤。

右側為一張完整七欄表，使用共通 `site-table-intrinsic` 的內容寬度與自動欄寬，不依 viewport 均分。字級維持 12px、列高維持 32px，增加值不拆行；移除上一輪窄螢幕對資料字級的額外縮小。

`site-table-column-scroll` 在七個 `data-site-column` 欄頭設定原生水平定位，`scroll-snap-stop:always` 讓滑動以相鄰欄位為停點，相鄰可視範圍保留已讀欄位。可見欄位數依手機寬度與所選品級最長數字自然決定，可露出下一欄；不再重建獨立子表或加入自訂觸控手勢。

固定左欄沿用共通固定欄排版契約，新增 `site-table-fixed-layout` 語意別名；既有六轉等頁的 `site-table-paged-layout` 不變。桌機排列、來源數據、圖片匯出及共通字重保持。本輪僅做必要語法檢查，實機目測由使用者確認。

## 第四輪：完整欄位與重疊分頁（2026-10-06）

本節取代第三輪的連續表格定位。原生欄頭定位只能對齊一側；另一側仍可能切開欄位，尤其滑到最大位移時無法同時對齊欄頭。

改以相同字級與列高的隱藏表量測每欄最長內容（無障礙與匯出排除），欄寬向上取整，以共通 `GMSMToolShell.columnPages` 按實際可用寬度安排完整欄位。下一頁從前頁最後一欄開始；最後一頁若仍有空間，向前補入能完整放下的已讀欄位。

每頁使用共通 `site-table-pages`／`site-table-page` 與整頁滑動定位；頁內表格使用量測後的內容欄寬，不均分拉大欄距。固定左欄、12px 資料字級、32px 列高和同行增加值保持。移除第三輪的 `site-table-column-scroll` 及欄頭定位規則。

切換品級、旋轉螢幕、字型載入後會重新量測與排列；切換頁面時會清除 ResizeObserver 與字型事件。桌機與完整圖片匯出仍使用原來的完整表格。

本輪僅執行 JS 語法及 19 組共通分組檢查，確認完整欄寬、重複欄、所有欄位可達及緊湊排列；未執行瀏覽器矩陣或圖片匯出驗證。

## 第五輪：滿版與數字對齊（2026-10-06）

仍以最小內容欄寬選出最多能完整顯示的欄位、保留重疊欄，之後將每頁剩餘寬度平均分配到已選欄位；餘數像素依序分配，表格寬度為可視區域 100%。此順序兼顧單屏資訊量與整頁滿版，沒有將更多欄位壓到不足的寬度。

新增共通 `site-table-number-pair` 和 `site-table-number-aligned`：每個資料欄分別量測主數值與增加值的最大文字寬度。主數值以固定槽位靠右排列，增加值另以固定槽位靠左排列；無增加值的成功率、材料與楓幣也以固定寬度靠右排列。同一欄不會因數值字數不同而偏移，整組仍置中在欄內。

量測在品級、螢幕寬度及字型變化時更新；數字同時適用桌機及完整圖片匯出。字級、列高、資料和整欄滑動規則保持。本輪僅做必要語法與分配算術檢查，手機顯示待使用者目測。

## 數字置中與百分號固定（2026-10-06）

BOSS 攻擊力、最終傷害與成功率採用共通 opt-in 元件 `site-table-number-unit`，將純數值與百分號分開。同一欄量測最大數值寬度並套用固定槽位，數字在槽位中置中、百分號緊接槽位右側，因此整數和小數的百分號位置一致，不補 `.0`。

零值連同百分號留白，其他非百分比欄位保持右側數字對齊。桌機、手機量測與分頁、完整圖片匯出使用同一顯示函式；手機重新依實際欄寬排列。共通元件需明確加入 class 才生效，其他工具保持既有排版。需求資料、字級與桌機閱讀內距不變。
