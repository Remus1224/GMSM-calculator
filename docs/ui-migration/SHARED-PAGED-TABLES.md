# 共通表格分頁排版（2026-10-05）

共通定義位於 assets/css/site-components.css，寵物食品與六轉核心皆已掛接。

| 元件 | 用途 |
| --- | --- |
| site-table-paged-scroll | 保留原生水平滑動，以完整分組為定位點 |
| site-table-pages | 分頁排列及共通 8px 間距 |
| site-table-page | 預設每頁占一個可視寬度，滑動停在完整一頁 |
| site-table-paged-layout | 固定左欄搭配可滑動主區域；工具依斷點控制是否 display:grid |
| site-table-page-grid | 每頁的內容分欄，預設兩欄 |

可調參數：--site-table-page-gap、--site-table-page-width、--site-table-fixed-column-width、--site-table-page-columns。

- 寵物表由私有雙欄 grid／200% 寬度算法改用共通分頁 flex；手機每段 100% 可視寬度，桌機用量測所得表格寬度覆寫分頁寬度。
- 六轉手機表的固定等級欄、雙核心分組格線由共通層管理；工具保留三種模式、數字、行高與標題／內容卡排列。
- 移除兩頁重複的分頁內距、固定欄格線與分組格線 CSS。實際數字字寬量測、各工具字級、欄位內容及響應式顯示條件繼續由工具設定。
- 共通玻璃、白底、橫線、移入效果及圖片匯出沿用既有共通層。

## 連續欄位滑動（2026-10-06）

- `site-table-fixed-layout` 與既有 `site-table-paged-layout` 共用固定左欄的 grid 契約，後者行為不變。
- `site-table-intrinsic` 提供內容導向的表格與欄位寬度；`site-table-column-scroll` 在 `data-site-column` 欄頭使用原生水平定位與逐欄停點，不將資料平均撐到整頁寬度。
- 輔助武器手機表改用這組元件，取消三張獨立子表，保持左側區間固定與右側完整資料連續滑動。其他需求表仍保留已驗收的整頁滑動方式。

## 完整欄位自動分組（2026-10-06）

- 輔助武器表取代前一版的欄頭定位，依內容字寬動態產生重疊分頁，滑動停止時兩側都是完整欄位。
- `GMSMToolShell.columnPages(widths, available)` 為共通純資料分組方法：以可用寬度放入最多完整欄位，相鄰頁重複交界欄，末頁向前補入可完整容納的欄位。
- 使用既有整頁原生滑動元件，保留內容欄寬；移除已不使用的連續欄位定位 CSS。其他表格不會自動改變排版。

## 滿版欄位與固定數字槽位（2026-10-06）

- 輔助武器先選完整欄位，再將剩餘可用寬度分配到選中欄位，填滿每個重疊分頁。
- 共通 `site-table-number-pair` 的兩個槽位分別使用 `--site-table-number-width` 與 `--site-table-detail-width`；主值靠右，次要數字靠左，工具提供實際量測寬度。
- 無次要數字可用 `site-table-number-aligned` 與 `--site-table-number-width`，確保每列數字右邊緣相同。其他表格不會自動更動對齊方式。

## 共通數字槽位對齊參數（2026-10-06）

- site-table-number-aligned 可透過 --site-table-number-align 調整槽位內對齊，預設 right；輔助武器指定 center，其他工具無需變動。數字槽位仍使用原有 --site-table-number-width 量測寬度，不影響完整欄位分頁算法。
- 百分比繼續使用 site-table-number-unit，純數字槽位置中、百分號固定在槽位右側。沒有重新調整資料或分頁規則，未進行驗證。
