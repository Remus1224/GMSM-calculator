# 單一網站與共通 CSS 整理

日期：2026-10-05。依使用者指示，停止維護重複的 Beta 網站，改以 Git 分支及本機預覽處理測試中的變更。

## Beta 移除

- 原本只有 Beta 才有的資訊首頁及五個表格、JSON、素材、匯出設定與交接文件，已移至根目錄 `game-info/`。
- 獨有的星辰代碼與海洛斯選單素材移至 `assets/menu/`。其他共用素材沿用正式站版本。
- 正式主選單改連至 `game-info/`；資訊頁的共通 CSS／JS、創世材料圖片與返回主選單路徑已調整。
- Beta 的祈禱預覽啟動工具移至正式祈禱目錄，改開正式路徑；沒有啟動或停止任何伺服器。
- 不同的 Beta 祈禱交接文件保留在 `PRAYER-BETA-HANDOFF-HISTORY.md`，標示為歷史資料。
- 正式站的威爾素材載入可靠性修補、祈禱 runtime 程式與原 runtime 引用保留。正式／Beta HTML 的其他差異是相對路徑，Beta shell 不含正式 shell 已有的資訊頁手機規則及表格定位輔助，保留正式版本。
- 原重複 Beta 目錄已移除。舊 `/beta/` URL 不再是網站入口；目前統一使用根目錄及 `/game-info/`。
- CI 與既有正式路徑檢查器的檔案路徑同步更新，未執行它們。README 分類與開發方式同步更新。

## 符文呼吸動畫

調閱發現，符文原提醒元素已由 `tool-shell.js` 取出文字並移除；實際顯示的提醒原本就在共通 `tool-shell.css` 使用 `siteNoticeBreath`。舊 `.rune-version-notice` CSS 與 `runeVersionNoticeBreath` 留在檔案中，屬於重複的舊呈現規則。

本輪將現行呼吸效果明確設為共通 `.site-note-breath`，由共通提醒元件套到重要提醒文字。保留 2.4 秒週期、原日夜透明度與減少動畫偏好處理。移除的是舊提醒外觀及舊動畫，不是使用者需要的現行呼吸效果。

原提醒資料改由隱藏的 `.site-source-note[data-tool-note]` 提供；共通元件依原位置顯示提醒。符文、創世計算機及六轉進度的提醒文字保留。

## 清理範圍與保留項目

- 移除未引用的 `.site-tinted-inset`。
- 移除符文舊提醒 CSS、夜間／手機／減少動畫的舊規則及舊 keyframes。
- 移除六轉進度舊 `.prog-note`、`.prog-common-note` 呈現規則，保留同樣提醒內容。
- 資訊表格原生邊框保留透明尺寸用途，線條由共通元件繪製。
- 不刪除 JavaScript 動態產生的六轉單級／累積、符文配色及裝備分類規則。
- 不移除原生選單的備援規則、舊遊戲主題變數、各工具欄寬／列高、手機捲動寬度、素材裁切、遊戲畫面及全螢幕樣式。
