# 六轉核心手機雙核心分頁（2026-10-05）

- 依使用者要求，720px 以下以固定 Lv.1～30 欄搭配兩個核心為一頁的水平滑動區。
- 第一頁：技能核心、精通核心；第二頁：強化核心、共用核心 I、II。等級欄在滑動容器外，不依賴浮動玻璃或遮色底。
- 單級、累積、綜合共用現行資料與運算順序；每次切换保留目前的兩核心分組。單級／累積保留合計，綜合維持原先不顯示合計。
- 使用共通 site-table-scroll 及新增 site-table-paged-scroll／site-table-pages／site-table-page，原生 scroll snap 以完整兩核心一組定位。左右方向鍵、Home、End 同樣以整頁移動，並尊重減少動態效果設定。
- 核心標題、內容與等級卡接上既有 hexa-title-card／hexa-body-card 共通玻璃；表格白底、內距、橫線及移入效果使用共通元件。手機內容卡內距採共通 field 8px，綜合模式採較小字級以容納每核心四個數值欄。
- 保留桌機原四核心完整表，手機呈現使用獨立且不重複的標題 IDs。手機各數值的無障礙名稱包含等級、材料、單級／累積及數量。
- 手機雙核心呈現標為 data-export-exclude；共通匯出於原 1120px 版面使用完整四核心表，不匯出重複的手機表。
