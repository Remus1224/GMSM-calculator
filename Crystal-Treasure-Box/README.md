# 水晶寶箱模擬器：開發預覽版

英文統一名稱：**Crystal Treasure Box**；正式路徑：`/GMSM-calculator/Crystal-Treasure-Box/`。

本目錄由開發分支完成驗收，正式網址為 `https://remus1224.github.io/GMSM-calculator/Crystal-Treasure-Box/`。首頁在光之聖所後方保留灰階停用入口。請由網站根目錄啟動靜態 HTTP 伺服器，再開啟 `/Crystal-Treasure-Box/`。直接使用 file:// 無法執行模組與素材載入。

## 目前功能與驗收

以 R21 B 的完整流程為基準，P3/P7/P32/P8 使用原貼圖與 Canvas2D，Lucky 使用 compact 烘焙圖集，不需要 Unity WASM/data。Canvas2D 是來源參數的近似實作；P3 中心光已依玩家確認關閉。

保留單抽、Normal 10+1、Fever、Lucky 接回同輪動畫、發卡、翻卡、Flip All、確認與音效。下方提供抽取與物品分類統計、靜音、完整重設。統計與靜音設定只存於本頁記憶體；重新整理歸零，素材 HTTP 快取不會一併清除。舊版 crystalchest.player.v1 紀錄會移除。

玩家已完成 iPhone 16 Pro Max 多輪目視測試，最後回報無明顯問題、溫度維持溫溫且未飆高。這不代表已證明所有裝置都能持續滿幀。診斷曾有較長畫面回呼間隔，其中部分與捲動離開模擬器相符；未重現的 Script error 不列為已修復。

清理版桌面自動檢查涵蓋單抽、10+1、真正 Lucky 與 Fever 接續、靜音、刷新歸零、抽取中重設、手機尺寸與全螢幕退回；逐筆檢查 Normal/Fever 共 268 筆卡片素材，無缺檔回應。第一、二輪清理版均已由玩家在手機確認沒有缺圖或特效異常。

## 素材與維護限制

`runtime/src/static-atlas-manifest.mjs` 將 125 個原始 PNG 路徑對應到五張無損圖集、91 個去重裁片。素材必須經既有 resource-loader 載入；不能把這些已移除的原始路徑直接指定給瀏覽器。125 張裁片與保留原圖逐像素相同。來源 SHA 與原始身分證據維持在契約中，不因移除來源副本而改寫。

本輪移除 277 個未使用檔案：125 張已由圖集取代的原圖、138 張僅供工程比較的 04 動畫影格、兩張舊 Lucky 完整圖集、12 個未引用舊模組。保留實際播放器使用的 22 張 03 影格。入口固定 player / compact Lucky，已不支援被移除素材的工程後端。

JSON 中某些歷史來源路徑是證據資料，並非現行下載需求。不可僅依 diagnostic、fixture 等名稱刪檔；部分同名資產、來源契約與 SHA 驗證仍供正式流程使用。字型為既有 WOFF2 子集；來源字型 SHA 與 runtime SHA 分開保留。`runtime/** -text` 用來保護位元組與雜湊。

素材快取由實際 HTTP 主機決定；區域網路已驗證重複使用快取，尚未實測 GitHub Pages／各電信商條件。檔案數量減少不等於每次進站下載量等比例下降，也不代表動畫效能同比改善。

## 現行減量版與驗收狀態

產品目前為 186 個檔案、約 42.00 MiB。相較初始 475 個檔案，累計移除 289 個檔案；20 張未綁定位元組 SHA 的 PNG 經無損重編碼，Pillow 與瀏覽器解碼 RGBA 都與原檔相同。有 SHA 綁定的素材保留原檔。

保留現行 p28p4r2 Fever 契約，移除兩份舊版契約與五份未引用工程資料。ASSET_MANIFEST.json 仍供商店使用，不能刪除。另移除四張未引用的介面比對圖與已關閉的 P3 中心光貼圖；Fever 的 16 張影格由程式動態組成路徑載入，全部保留。

沒有減少動畫影格、修改解析度或降低影片畫質。第一、二輪已通過玩家手機驗收；第三輪僅移除未引用素材，功能與 268 筆卡片素材自動檢查報告存於研究工作區 exports/CrystalChest_Cleanup3_20261125。依網站既有 PR／CI／main 流程發布。

進一步合併圖集、改寫場景資料結構或精簡工程程式，均涉及執行路徑改動，應另作候選版與回歸驗證，不當作可直接刪除的檔案處理。

公開靜態網址沒有存取控制；noindex 只要求搜尋引擎不要收錄。原始來源契約的 CrystalChest schema 與歷史 localStorage 清理鍵保留，避免破壞相容性與驗證。發布已獲維護者授權；實際部署狀態以 GitHub Pages 為準。
